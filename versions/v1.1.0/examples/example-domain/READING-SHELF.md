# READING-SHELF.md - Book Catalog

> **Example domain file.** Fictional content showing a leaf file. This leaf is the durable catalog of every finished book with a one-line verdict. It loads on demand when you need a past book's verdict or rating - never at session startup. The QUEUE is ephemeral (the active worklist); the shelf is the long memory (every book, forever).

Verdict format (per trunk conventions): `Book (Rating) - one sentence on what it was actually about and whether it delivered.`
